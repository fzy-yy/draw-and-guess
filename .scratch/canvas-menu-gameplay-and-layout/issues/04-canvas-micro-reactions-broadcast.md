# 04: 画布全员轻量微表情广播（👍 / ❓ / 🔥）

**What to build:** 猜词者与观战者通过画板右键菜单点击微表情（👍、❓、🔥），向服务端发送轻量坐标事件；服务端在校验房间规则开启且未超频后，向房间内全员实时广播；所有玩家（含画家）在画板对应坐标看到小表情气泡浮起淡出，点燃局域网派对气氛。该事件不入数据库持久化、不入权威绘图命令历史，对画布重放与性能零负担。

**Blocked by:** 01: 协议与房间设置底座（差一字与微表情开关）, 03: 画板双角色右键菜单与画作导出

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 协议新增 `game:canvas_ping` 事件契约，载荷包含归一化坐标 `(x, y)` 与表情类型（`thumbs_up`、`confused`、`fire`）
- [ ] 猜词者与观战者右键菜单中渲染微表情选项（点赞 👍、满头问号 ❓、神仙画画 🔥）
- [ ] 客户端与服务端双重实施单人 1.5 秒滑动窗口冷却限制，防止狂点刷屏
- [ ] 若房间规则 `allowCanvasReactions === false`，右键菜单中表情项置灰且服务端拒绝处理
- [ ] 全员客户端在画板对应坐标渲染飘动气泡，沿 Y 轴上浮并在 1.2 秒内淡出消失
- [ ] 客户端画板维护临时气泡队列，上限严格限制为最多 6 个，超出时自动淘汰最旧气泡
- [ ] 微表情纯作为瞬态广播，绝不写入权威笔画历史，不触发重放状态机重绘
