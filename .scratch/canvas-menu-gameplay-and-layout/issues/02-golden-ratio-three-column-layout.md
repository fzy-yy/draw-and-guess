# 02: 黄金平衡三栏对局布局重构（16% - 62% - 20%）

**What to build:** 对局界面彻底废除遮挡画布的浮动聊天面板（FloatingPanel）与快捷键 C 显隐控制，转为「全局统领顶栏 + 左侧 16% 舒展玩家榜 + 中间 62% 4:3 黄金画板 + 右侧 20% 舒适常驻聊天栏」的经典三栏布局。左侧玩家栏可完整展示 8~~10 字昵称不截断；画板居中作为全屏绝对主角，零遮挡、永不拉伸伸缩；右侧聊天单行容纳 15~~16 汉字，短句猜词不折行，猜词者边看画边打字，手感极其丝滑。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 对局视图采用 100cqw 精确物理空间布局：左栏 `16cqw` + 间距 `0.8cqw` + 中栏 `62cqw` + 间距 `0.8cqw` + 右栏 `20cqw` + 外留白各 `0.2cqw`
- [ ] 顶部保持统一的全局统领顶栏（`StageHeader`，约 9%~10% 高度），各视图基线与高度统一
- [ ] 左侧玩家栏采用独立黑框包裹，文字净宽达到 120px 以上，8~10 字长昵称与分数优雅分两行展示且不发生溢出截断
- [ ] 中间画板采用独立黑框包裹，宽高比达到约 1.28:1（4:3 经典黄金画画比例），居中绝对主角，全屏 100% 完整可见，零浮窗遮挡
- [ ] 彻底移除浮动面板组件（`FloatingPanel`）、面板拖动逻辑与快捷键 C 显隐开关
- [ ] 右侧聊天栏采用独立黑框包裹，回归流内常驻右栏，上部为高密度滚动消息流，底部为单行输入框与发送按钮
- [ ] 画家底部工具条浮动显示在画板内部底部，支持拖动手柄轻微避让，猜词者视角完全隐藏
- [ ] 组件与集成测试验证新三栏结构，废除旧浮动面板测试断言
