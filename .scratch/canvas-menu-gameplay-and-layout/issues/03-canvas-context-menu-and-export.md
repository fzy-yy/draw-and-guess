# 03: 画板双角色右键菜单与画作导出

**What to build:** 在画板区域拦截右键事件，复用全局单例右键菜单（`ContextMenu.vue`），根据当前玩家角色动态弹出对应菜单。画家可就地进行工具切换（画笔/橡皮/油漆桶/吸管）、历史控制（撤销/重做）、复制画作到剪贴板、下载 PNG 图片与清空画板（触发二次确认弹窗）；猜词者与观战者可复制/下载画作并发送快捷短语。菜单具备作画中防误触、点击外部关闭不留杂墨、以及局域网 HTTP 下剪贴板自动降级为文件下载的自愈能力。

**Blocked by:** 02: 黄金平衡三栏对局布局重构（16% - 62% - 20%）

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 画布容器拦截 `@contextmenu.prevent`，通过 `useContextMenu().open` 在指针坐标弹出菜单
- [ ] 画家视角显示完整创作菜单：画笔 (B)、橡皮 (E)、油漆桶 (F)、吸管取色、撤销 (Ctrl+Z)、重做 (Ctrl+Y)、复制画作、保存图片、清空画板
- [ ] 当前已激活的工具在菜单中正确显示为禁用置灰或选中标记；无撤销/重做历史时对应项置灰
- [ ] 吸管取色点击后光标变吸管，在画板单点取色后自动切回画笔工具
- [ ] 清空画板项带有 `danger: true` 警示样式，点击后弹出 `ConfirmDialog` 弹窗确认，确认后方执行清空
- [ ] 猜词者与观战者视角弹出专属菜单：复制画作、保存图片、快捷发言短语
- [ ] 处于作画中（`drawing.value === true`）时彻底忽略右键，防止快速划线被打断
- [ ] 右键菜单展开期间，点击画板空白区域仅关闭菜单，阻断墨迹生成，画板 100% 保持纯净
- [ ] 导出源直接取自 720p 纯净逻辑画布；`navigator.clipboard.write` 在非 HTTPS 或权限受阻时自动降级为触发文件下载并弹出 Toast 提示
