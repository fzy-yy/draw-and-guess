# 05: 猜词「差一个字」私密提示与全员猜中立即提前结算

**What to build:** 猜词者在作答时，若猜词与正确答案仅相差一个字（两字及以上词有效），服务端自动向该猜词者独占 Socket 发送私密提示（公屏不泄漏），聊天流以专属淡橙色样式提示“💡 离答案只差一个字了”，不限提醒次数，激发猜词动力；当房间内所有在线猜词者全部答对时，服务端立即提前结束当前作画阶段并切入回合结算，零等待消除垃圾时间。

**Blocked by:** 01: 协议与房间设置底座（差一字与微表情开关）, 02: 黄金平衡三栏对局布局重构（16% - 62% - 20%）

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 共享包实现 Levenshtein 编辑距离纯函数与单字不提醒边界判定
- [ ] 服务端在猜词未命中时进行差一字比对：答案字数 $\ge 2$、编辑距离严格等于 1 且房间 `allowNearMissHint === true` 时触发
- [ ] 差一字提示仅向当前猜词者的独占 Socket 定向推送私密事件，其他玩家与公屏绝对不泄漏答案线索
- [ ] 单回合内差一字提示不限次数，只要符合条件即刻予以正向反馈
- [ ] 客户端聊天流将私密提示以淡橙色微底色（`bg-yellow/15`）、细线边框和 `💡` 图标专属样式渲染，与普通发言明显区隔
- [ ] 服务端在猜词命中后统计已猜中人数，若达到当前在线猜词者总数（`totalGuessers`），立即取消倒计时定时器，切入 `round_result` 阶段
- [ ] 自动化测试使用假时钟验证全员猜中提前结算与差一字私密通知的完整端到端行为
