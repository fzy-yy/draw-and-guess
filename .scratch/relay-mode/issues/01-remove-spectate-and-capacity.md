# 01: 删除观战 / 候场 / 人数上限（两模式生效）

**What to build:** 玩家在房间里再也看不到「观战」「下一局加入」与「人数上限」这三样东西：开局之后公开房、私密码、邀请三条加入路径一律被拒（大厅与房间的加入入口置灰显示「游戏中」），房间容量固定为 6 人且房主不可调整。经典模式除这些删除之外，玩法、界面与行为与改动前逐条一致。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 协议层不再有中途加入策略枚举与人数上限字段；房间设置、成员状态、角色裁剪快照中与之相关的字段与派生一并移除
- [ ] 服务端：开局后任何加入请求（含私密码与邀请）都被拒；不再有「候场者下局晋升」「观战者不占席」等分支；邀请的容量判定改用固定容量常量
- [ ] 客户端：建房与规则弹窗不再有「人数上限」「中途加入策略」字段；等待页席位与大厅房间行改用固定容量；开局后加入入口置灰并显示「游戏中」
- [ ] 既有的候场 / 观战专题文档，以及覆盖它们的单测、组件测、e2e 操作步骤，同步删除或改造
- [ ] 经典回归：阶段流转、准备、踢人 / 移交房主、邀请、断线恢复的既有测试全绿
- [ ] 依据：`spec.md` 的「全局性删除」；共识 S36 / S61 / S67
