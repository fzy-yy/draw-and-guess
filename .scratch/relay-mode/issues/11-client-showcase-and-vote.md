# 11: 客户端：复盘展示与投票卡

**What to build:** 复盘期玩家按服务端的节奏看到一条链的完整故事：顶栏左右两个「头像 + 昵称」全程**不移动**（画家带画笔角标、猜词者不带），两个答案 UI 负责揭晓、平移与渐隐，未揭晓的答案用与经典模式一致的下划线占位，链条进度写在最左侧标签之后；轮到投票时画布上浮出投票卡：两个答案底色一致，票行按到达顺序匿名实时插入 ✔/✘ 且不带底色，点下即锁定；左侧玩家栏同步显示「已投票 / 未投票」。

**Blocked by:** 08, 09

**Status:** ready-for-agent
