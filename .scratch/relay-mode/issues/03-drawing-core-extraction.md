# 03: 抽取绘图纯函数内核（经典行为逐条不变）

**What to build:** 把「自由笔画与区域填充如何进入权威历史」从房间概念里彻底剥离，成为一组纯函数：吃一份画布状态与一条命令，吐回新状态或一个拒绝原因——涵盖序号单调、历史只增不删、命令 / 点数 / 填充三档预算、撤销重做栈与清空。经典绘图服务退化为「会话解析 + 预算门禁 + 注入发布策略」的薄协调层，此时只注入经典的「全房广播」策略。完成后经典模式的绘图体验与线上表现必须**逐条不变**。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 绘图内核是纯函数、不依赖房间 / 成员 / 传输；画布状态仍留在领域模型里，可被快照与画布同步游标直接读写
- [ ] 绘图协调层只负责解析目标画布、执行内核、并调用注入的发布策略
- [ ] 经典回归全绿：历史上限「拒绝新增而非丢弃最旧」、点数与填充预算、撤销重做、旧包拒绝、增量重连与整帧重放、差分游标
- [ ] 依据：`spec.md` 的「服务端领域」；共识 S49；ADR-0010 / ADR-0017 / ADR-0018
