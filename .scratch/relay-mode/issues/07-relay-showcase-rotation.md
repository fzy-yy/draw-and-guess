# 07: 接龙复盘轮播（按席位顺序逐链展示）

**What to build:** 四个步骤走完后，全员统一步调进入复盘：按链发起人的席位顺序逐条展示。每条链分两个半场——重播第一幅画 → 停顿 → 揭晓第二棒猜出的答案；重播第二幅画 → 停顿 → 揭晓第四棒猜出的答案——每条链展示完接一次该链的投票。展示期间**没有任何人能干预**（不能跳过、也不能提前结束），有人掉线或离开也不影响轮播继续；复盘期玩家能看到该链的两幅画与两个答案。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 复盘按链发起人席位顺序推进；服务端持有「当前链 + 当前半场 + 当前页」的权威游标并随快照下发
- [ ] 每半场时序：重播（3s）→ 停顿（1s）→ 揭晓（3s）；三个时长进公开配置包，不写魔法数字
- [ ] 展示期拒绝「跳过」与「提前结束」类请求；成员变动不中止轮播
- [ ] 复盘期快照向全员公开**当前链**的两幅画与两个答案，同时仍不下发其余链的任何内容
- [ ] 测试：用假时钟推进断言链顺序与每链总时长；展示期不可干预的拒绝路径
- [ ] 依据：`spec.md` 的「服务端领域」；共识 S11 / S12 / S32 / S43 / S65
