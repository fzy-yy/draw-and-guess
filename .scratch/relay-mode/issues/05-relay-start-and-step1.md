# 05: 接龙开局与步骤 1（选词 → 作画）

**What to build:** 4 名在线且已准备的玩家可以在接龙房里真正开一局：全员同时进入选词（20 秒，各自从自己的候选词里挑），全员选完立即秒切作画；选词超时的人由服务端随机代选（绝不出现空白画布）。作画阶段每人只拿到**自己那条链**的候选词与画布。到这一步为止，服务端已能独立跑通「开局 → 步骤 1 → 进入步骤 2」。

**Blocked by:** 02, 04

**Status:** ready-for-agent

- [ ] 开局门禁：在线且可玩的成员 ≥ 4（门槛取共享协议常量）且全员准备；不满足时返回明确拒绝
- [ ] 选词阶段：每人独立候选（不跨链去重）、可换一批、可自定义题目；全员选完秒切作画；倒计时结束仍未选的人由服务端随机代选
- [ ] 作画阶段：题面为本人的词，且只有本人能画自己链的画布
- [ ] 角色裁剪：本步快照只出现该玩家本棒所需的链内容；其余链的画作与答案、他人的候选词一律不出现
- [ ] 测试缝：新增「接龙装配件」——一次调用得到「4 人接龙房 + 词库 + 已开局」，并能把该局推进到指定幕（第 N 棒 / 复盘的某条链某半场 / 投票中 / 终局）；接龙服务端测试统一以它为起点
- [ ] 依据：`spec.md` 的「服务端领域」与「Testing Decisions」；共识 S9 / S31 / S35 / S40 / S62
