# 04: 接龙画布通路（写入链内历史、不广播）

**What to build:** 在接龙模式里，玩家可以在**自己这一棒负责的那条链**的画布上作画（画笔 / 橡皮 / 填充 / 撤销 / 重做 / 清空），服务端把命令写进该链的权威历史，但**不向房间广播**——其他客户端在这幅画被交接给他们之前，收不到任何一笔。每幅画的命令数、点数与填充次数按幅独立计数。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 绘制目标由「观看者 + 当前步骤标识」解析到具体链的画布；越权（不是本棒作画者）被拒
- [ ] 接龙下绘图命令**不触发房间级广播**；服务端只在交接时把整幅画随快照发给下一棒玩家
- [ ] 每幅画独立的命令 / 点数 / 填充预算，达到上限按既有「拒绝新增」口径处理
- [ ] 撤销 / 重做 / 清空在接龙画布上与经典语义一致
- [ ] 测试：断言「同一房间内其他玩家在本棒期间收不到任何绘图推送」，以及预算与撤销的行为
- [ ] 依据：`spec.md` 的「服务端领域」；共识 S2 / S45 / S51 / S53
