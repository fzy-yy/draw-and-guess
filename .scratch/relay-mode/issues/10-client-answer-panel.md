# 10: 客户端：接龙作答浮层与提交进度

**What to build:** 轮到猜词时，玩家在画布上看到一个**可拖动的输入浮层**，写下答案并提交；提交后立即锁定并显示「等待其他玩家」；左侧玩家栏实时显示每个人「已提交 / 未提交」（不显示数目）。当服务端因为超时或掉线替他代交时，界面同步到已提交状态。作答内容不会出现在右侧聊天流里。

**Blocked by:** 08, 09

**Status:** ready-for-agent

- [ ] 作答浮层可拖动（共用从底部工具条抽出的拖动外壳），输入框与按钮复用既有原语
- [ ] 提交后锁定并显示等待态；输入为空时提交按钮不可用；输入上限与聊天一致
- [ ] 左侧玩家栏按快照渲染「已提交 / 未提交」，本人与他人均可见
- [ ] 服务端代交（超时 / 断线）后界面同步为已提交
- [ ] 集成测试：作答与聊天互不串（聊天走独立事件、作答不进入聊天流）
- [ ] 依据：`spec.md` 的「客户端」；共识 S20 / S41 / S72 / S79 / S86
