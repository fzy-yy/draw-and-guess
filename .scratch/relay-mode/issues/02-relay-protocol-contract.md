# 02: 接龙协议契约（阶段 / 步骤 / 设置 / 事件 / 视图 schema）

**What to build:** 共享协议里出现接龙所需的全部线上契约：房间可以在建房时声明自己是接龙模式；接龙拥有自己的阶段序列与步骤标识；与作答和绘图相关的新请求都有严格 schema 与统一 ack；房间快照多出一个「按观看者裁剪的接龙视图」字段（经典字段保持不动）。这一步结束时还没有任何接龙玩法，但契约已被测试钉死，两端可以对同一份契约开工。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 房间阶段新增 5 个接龙阶段，并与经典阶段共存于同一份合法转换白名单（`paused` 在接龙不可达）。转换链形状如下（来自设计共识，非实现代码）：

  ```text
  starting → relay_choose → relay_draw(步1) → relay_guess(步2)
           → relay_draw(步3) → relay_guess(步4)
           → relay_showcase ⇄ relay_vote → game_result → waiting
  ```

- [ ] 房间顶层新增模式字段（与可见性同级、创建时确定、房间内不可修改）
- [ ] 房间设置删除人数上限与中途加入策略，新增接龙三时长，取值为白名单档位（选词 10/15/20/30、作画 60/90/120/150、猜词 30/45/60/75，默认 20/90/45）
- [ ] 新增 8 条客户端请求事件与对应 ack：5 条接龙绘图（笔画批次 / 填充提交 / 撤销 / 重做 / 清空，用步骤 id 定位目标画布）、2 条提交（提交答案带文本、提交作画只标记完成）、1 条独立聊天（仅接龙使用）
- [ ] 房间快照新增可选接龙视图字段（严格 schema、按观看者最小集）：阶段 / 当前步骤 / 步骤标识 / 阶段时间 / 本链产物 / 我是否已提交 / 复盘期的链序号与半场 / 顶栏双胶囊内容 / 匿名票行
- [ ] 大厅房间行含模式标识、不含人数上限字段
- [ ] 协议版本号升到不兼容的新版本
- [ ] 协议边界测试：请求 schema 与响应契约逐事件配对、错误码穷尽、客户端请求边界扫描——新增事件漏登记即失败
