# 规格：对局界面重设计（浮层布局）与移除结构化提示

> **Status**: ready-for-agent
> 来源：2026-10-01 用户提出「按当前原型改造对局界面 + 删除提示」，经 grilling 三轮访谈收敛。
> 原型：`prototypes` 分支的 `apps/client/prototype/game-layout/`（唯一版本「底部工具条」；原型不留在 `main`）。
> 关联决策：[ADR-0042](../../docs/adr/0042-remove-structured-hints.md)、[ADR-0043](../../docs/adr/0043-game-view-floating-layout.md)。

## Problem Statement

当前对局界面是 **3×3 网格**（`17% | 61% | 22%` × `11% | 76% | 13%`）：

- **画布偏小**：只占中间 61%，玩家得分条与聊天各占固定一列，工具栏再占底部 13%，画布被三层固定分区挤压。
- **顶栏冗余偏高**：同时显示「当前画家」与「结构化提示」，与玩家面板、题目遮罩重复；顶栏 11% 的高度进一步压缩画布。
- **提示泄露线索**：结构化提示把词条 `hint`（如「草原上的高个子」）当作对局提示披露给猜词者，等于把词库元数据带进对局，显著降低猜词难度，也与题目遮罩表达同一类信息。
- **布局僵化**：得分条、聊天、工具栏都固定占位，玩家无法按需要把面板收起来换取更大的画布。

## Solution

把对局界面改为「**固定顶栏 + 铺满画布 + 浮动面板 + 底部横向工具条**」，并移除结构化提示：

- **顶栏收窄**：`ROUND` 放在最左，面板开关按钮排在其右侧向右排列；删掉「当前画家」信息块与结构化提示区；保留题目、倒计时、网络状态、暂停、设置、全屏。高度取舞台高度的 `11%`，与大厅 / 房间 / 设置页顶栏一致（见 ADR-0044）。
- **画布铺满**：顶栏以下整块都是画布，只留线性边距；画布加黑色描边、圆角（与浮层圆角同值）与极小边距。
- **面板浮层化**：**玩家面板为常驻左栏**（在流内占位、挤窄画板，不浮动、无标题栏、不可关闭），**聊天为浮层面板**（可拖动、可关闭、默认打开，纵向撑满画布高），出入场统一为「淡入淡出 + 缩放」；聊天面板的顶栏开关与面板内关闭按钮双向同步。
- **底部工具条**：绘图工具改为浮在画布底部、无阴影、单行、与图标按钮尺寸相适应的横向长条；除画笔大小数值外不显示文字，可由顶栏「工具」按钮开关。
- **移除结构化提示**：词条 `hint` 不再进入对局链路；猜词者只靠逐步揭示的**逐字遮罩**与画作推理。房间规则里的「结构化提示」与「提示出现时机」一并删除。

## User Stories

1. 作为猜词玩家，我想要画布尽可能大，以便看清画作细节。
2. 作为猜词玩家，我想要玩家与聊天面板可以收起，以便在需要时把整块画面让给画布。
3. 作为猜词玩家，我想要面板可以拖动到不挡画作的位置，以便边看画边聊天。
4. 作为猜词玩家，我想要面板关闭后仍能从顶栏一键重新打开，以便不用找菜单。
5. 作为猜词玩家，我想要面板显隐有统一的淡入淡出缩放动画，以便察觉状态变化且不被突然出现的内容打断。
6. 作为猜词玩家，我想要顶栏只保留回合、题目、倒计时与系统操作，以便视线集中在题目与时间上。
7. 作为猜词玩家，我想要 `ROUND` 在最左、面板开关紧随其后，以便第一时间读到当前回合。
8. 作为猜词玩家，我想要看不到任何「提示」文案，以便依靠画作与逐字遮罩推理。
9. 作为猜词玩家，我想要逐字遮罩仍然按节奏揭示字符，以便难度不至于陡增。
10. 作为正在作画的玩家，我想要底部有一条只占一行的工具条，以便不遮挡画布上部。
11. 作为正在作画的玩家，我想要工具条只用图标、只有画笔大小显示数值，以便在窄条里快速点选。
12. 作为正在作画的玩家，我想要画笔大小可 hover 预览粗细、滚轮直接调整，以便不离开工具栏就调好笔宽。
13. 作为正在作画的玩家，我想要工具条可以整体收起，以便临时把画面让给画布。
14. 作为正在作画的玩家，我想要调色用与之前一致的圆形纯色色块，以便保持肌肉记忆。
15. 作为正在作画的玩家，我想要画布有与浮层一致的圆角与黑色描边，以便视觉边界清晰且风格统一。
16. 作为房主，我想要房间规则里不再出现「结构化提示」与「提示出现时机」，以便规则页只反映真实生效的配置。
17. 作为房主，我想要「逐步提示字符」开关仍然可用，以便需要时完全关闭逐字遮罩。
18. 作为房主，我想要词库弹窗不再展示「提示」列，以便界面不呈现与对局无关的信息。
19. 作为玩家，我想要玩家面板更窄、只容纳头像与文字，以便不遮挡画布。
20. 作为玩家，我想要玩家面板不再显示「我」标记，以便列表更紧凑。
21. 作为玩家，我想要在玩家面板里仍能看到谁是画家、谁已猜中、谁掉线，以便掌握局面。
22. 作为对局中断线重连的玩家，我想要重连后顶栏与面板状态与我离开前一致（按服务端快照重建），以便不迷失。
23. 作为开发者，我想要对局界面的重复样式收敛为共享组件，以便后续调整只改一处。
24. 作为开发者，我想要删除 ScoreStrip 与 DrawingToolbar 这两个被替代的旧组件，以便不留死面。
25. 作为开发者，我想要提示相关文案与协议字段一并清理，以便不留「可点但无效」的开关与死字段。
26. 作为开发者，我想要这次改动有对应的 ADR 与词表更新，以便后人理解「为什么去掉提示」「为什么改成浮层」。

## Implementation Decisions

### 协议与配置（不兼容变更，`protocolVersion` 14 → 15）

- 房间设置 Schema 删除 `structuredHintsEnabled`、`hintStartRatio`（保留 `progressiveHints`）。
- 推送 Schema 删除 `wordHint`、`revealedHints`（保留 `answerMask` 与逐字遮罩）。
- 共享常量删除 `hintStartRatio` 区间；公开配置删除 `structuredHintsEnabled` / `hintStartRatio` / `hintStartRatioRange`，保留 `progressiveHints` / `progressiveHintRatio`。
- 客户端与服务端必须同步构建部署（版本握手会拦下过期客户端）。

### 服务端

- `hint-scheduler.ts` 去掉结构化提示分支，只保留逐字遮罩调度（模块仍在，仍是揭示节奏的唯一事实来源）。
- `round-machine.ts` 不再写入/揭示结构化提示；`models.ts` 删除 `structuredHint` / `structuredHintRevealed`（保留逐字计时器字段）。
- `snapshot.ts` 不再下发 `wordHint` / `revealedHints`；快照矩阵的 `FORBIDDEN_KEYS` 同步收缩。
- 词库 Provider 仍解析并校验 `hint` 列（词库数据语义不变），但对局链路不再读取它。

### 客户端组件（可维护性与模块化）

新增共享组件：

- `FloatingPanel`：浮层面板壳——标题栏拖动、关闭、统一「淡入淡出 + 缩放」出入场；位置以相对画布区的百分比记账并夹取在工作区内。
- `PlayerPanel`：收窄的玩家列表（头像 + 昵称 + 分数 + 局内角色 + 座位色条），不含「我」标记。
- `CanvasToolbar`：底部横向工具条（工具 / 色板 / 画笔大小 / 历史），无阴影。
- `BrushSizeField`：画笔大小数值控件——只显示数值，悬停时鼠标指针变为与当前粗细同直径的画笔圆点，滚轮调整。

提升为 `components/common/` 共享原语（消除相同样式的重复类串）：

- 方形图标按钮（顶栏面板开关与工具条按钮共用同一底座与激活态）。
- 圆形色板按钮（预设色 + 自定义取色，统一选中环）。
- 分组分隔线。

复用现有：`HudPill`（顶栏胶囊）、`IconButton`、`ToolButton`。

改造与删除：

- `GameHud`：删「当前画家」与提示区、并入面板开关、高度与其它页面顶栏统一（`11cqh`）。
- `GameView`：由 3×3 网格改为「顶栏 + 铺满画布 + 浮层 + 底部工具条」。
- 删除 `ScoreStrip`、`DrawingToolbar`（被 `PlayerPanel` / `CanvasToolbar` 取代）。
- 词库弹窗删除「提示」列；房间规则弹窗与规则摘要删除提示两项、保留「逐步提示字符」。
- 文案表删除提示专属条目（提示徽章、未揭示占位、结构化提示规则项等），并改写提到「提示」的画家答案显隐文案。

### 布局与交互尺寸（与原型一致）

- 顶栏高度为舞台高度的 `11%`（与大厅/房间/设置页统一）；画布区留 `0.7cqh / 0.7cqw` 边距、`0.35cqh` 黑色描边（直角，无圆角）；玩家面板 `10cqw`、`h-full`，在流内占位于画板左侧（不浮动、直角、不可关闭、无开关与快捷键）；聊天面板 `24cqw`、`h-full`，浮在画板右缘、可拖动、保留圆角。
- 玩家面板 `10cqw`、聊天面板 `24cqw`，均 `h-full`（撑满画布高）；聊天面板默认打开、贴右缘，玩家面板为常驻左栏。
- 底部工具条浮于画布底部居中，仅一行高、与图标按钮尺寸相适应，默认打开。
- 面板与工具条显隐：淡入淡出 + 缩放（进入 180ms / 退出 140ms）。

## Testing Decisions

好的测试只断言**外部行为**（协议边界、快照可见性、界面可观察结果），不锁实现细节（内部字段名、组件私有方法）。

- **单元**（`test/unit`，镜像现有 `hint-scheduler` / 快照矩阵用例）：
  - 揭示调度：仅逐字遮罩节奏（到点揭示、保留末尾非标点字符、长答案不坍缩）。
  - 快照矩阵：移除 `wordHint` / `revealedHints` 的可见性断言，`FORBIDDEN_KEYS` 收缩后仍通过角色×阶段穷举。
  - 协议 Schema：room settings 与 push 的正/负向配对（`test/type/schema-first.ts` 同源）。
- **组件**（`test/component`，镜像 `GameInteractionSurfaces` 等）：
  - `FloatingPanel`（开合、拖动夹取、点击关闭、顶栏开关联动）。
  - `PlayerPanel`（无「我」标记、画家/已猜中/掉线标记）。
  - `CanvasToolbar` / `BrushSizeField`（工具切换、hover 圆点、滚轮调值、非画家置灰）。
  - `GameHud` 更新（无提示区、无当前画家、开关可用）。
  - 删除/改写 `ScoreStrip`、`DrawingToolbar` 的既有用例。
- **集成 / E2E**（`test/integration`、`test/e2e/specs/03-game-drawing`、`04-game-guessing`、`05-game-lifecycle`）：
  - 对局界面按新骨架渲染、面板可开关、底部工具条可开关、猜词者看不到任何提示文案。
- **最高缝**：`GameView` 的端到端行为（E2E 对局用例）。这是新布局唯一能一次性覆盖「顶栏 + 画布 + 浮层 + 工具条」协同的缝，优先在此加断言。
- 文档一致性：`test/unit/documentation.consistency.spec.ts` 会校验 `AGENTS.md` / `README.md` 中的反引号路径，组件增删必须同步文档。

## Out of Scope

- 词库数据库的 `hint` 列与其加载期校验（保留，属词库数据）。
- 大厅、房间等待页、设置页的布局（仅因删协议字段而同步删规则 UI 两项与词库弹窗的提示列）。
- 逐字遮罩（progressive hints）本身的节奏与算法（保留）。
- 移动端 / 触屏专属适配（沿用既有「主要适配电脑浏览器、等比缩放」口径）。
- 面板缩放、磁吸、布局持久化（刷新即重置）。

## Further Notes

- 原型位置与运行：`prototypes` 分支的 `apps/client/prototype/game-layout/`（先 `git checkout prototypes`），`pnpm --filter @draw-guess/client dev` 后访问 `/prototype/game-layout/index.html`；原型只是视觉参照，不作为交付物。
- 本规格**取代**此前提案中的三变体原型方案（`A 浮卡 / B 半透明 / C 贴边 / D 底部工具条`）；最终只保留「底部工具条」版。
- 删除结构化提示同时会使 [ADR-0032](../../docs/adr/0032-drawer-hint-full-and-progressive.md) 废弃、[ADR-0013](../../docs/adr/0013-vocabulary-level-config-and-hints.md) 的提示部分仅剩词库数据语义（见 ADR-0042）。
- 协议为不兼容变更，落地时前后端需同批部署；旧页面刷新即被版本握手拦下。
- 后续调整：顶栏高度在实现后由 `9cqh` 回调为舞台高度的 `11%`（与大厅/房间/设置页统一），并新增面板显隐快捷键（C/T 可配置 + 回车只开不关），见 `docs/adr/0044-panel-shortcuts-and-unified-topbar.md`；玩家面板最终改为**常驻左栏**（在流内占位、不浮动、不可关闭），其顶栏开关与快捷键一并移除。
