# T01 · 房间规则：单回合时长四档 + 选词阶段时限开关

**Status**: ready-for-agent
**Blocked by**: —

> 依据：`.scratch/custom-word-and-simplification/spec.md`「批次 ①」。

## 目标

房主能在房间规则里把单回合时长设为 60 / 90 / 120 / 150 秒（默认 120），并决定选词阶段是否计时（默认不计时）；对局严格按新口径推进，词条不再参与时长决定。

## 范围

- **共享契约**：房间规则 `drawSeconds` 由「45–180 区间 + 步进 15」收窄为四档白名单字面量联合（默认 120）；新增 `allowChooseTimeLimit`（默认 `false`）；删除 `extraGuessSeconds`；`PROTOCOL_VERSION` `'15'` → `'16'`。Zod Schema 的负向用例同步（105 / 135 这类旧值必须被判非法）。
- **公开配置**：`app.version` `2.5.0` → `2.6.0`；房间规则默认值改为 120 秒 + `allowChooseTimeLimit: false`；删除额外猜词时间的区间与默认值。
- **服务端**：回合时长恒等于房间 `drawSeconds`，删除词条派生时限的读取与服务端私有开关 `useWordTimeLimit` 的参与（词条字段本身由 T02 删除）；选词阶段按开关决定是否写 `phaseEndsAt` 与是否挂超时定时器——关闭时 `phaseEndsAt = 0`、无计时器、无自动代选，沿用既有「`0` 表示未到期」的哨兵语义；开启时恢复 `chooseSeconds`（10–30，默认 15）与超时随机代选。
- **断线兜底**（无时限时的唯一自动路径，沿用既有机制）：画家断线或离局且宽限期结束仍在选词阶段时，本回合作废并顺延到下一回合选词；不做「离线画家代选后继续作画」。
- **客户端规则弹窗**：单回合时长改用 `SelectDropdown` 四档；新增「选词阶段时限」开关，关闭时 `chooseSeconds` 行置灰并显示「不限时」，开启时可编辑；规则摘要同步新增一条。
- **客户端对局界面**：`phaseEndsAt` 为 `0` 时不渲染倒计时、不播倒计时警示音；选词遮罩在关闭时显示「不限时」而不是「N 秒后自动选择」。
- **文案表**：新增/改写规则项、规则摘要与倒计时文案；删除「作画时间回退」「额外猜词时间」相关条目。
- **测试**：回合时长、`phaseEndsAt` 哨兵、开关两种状态下的选词阶段行为、断线代选、协议正负向配对、规则弹窗组件用例。

## 非目标

- 词条字段的删除（T02）、计分（T03）、自定义词（T04）。
- 选词阶段的暂停语义变更：暂停机制保持现状，无时限时它只是标记暂停，不产生额外语义。
- 房间规则其它项（回合数、候选个数、显示词长、逐步提示、暂停、换一组、玩家邀请、加入策略）。

## 验收

- [ ] 房主可选 60/90/120/150 四档时长，非法值被服务端拒绝；房间快照与规则摘要与所选值一致。
- [ ] 单回合实际时长等于房间设置，且与词条无关。
- [ ] 「选词阶段时限」默认关闭：选词阶段无截止时间、不自动代选，`phaseEndsAt` 为 `0`，界面不显示倒计时。
- [ ] 开关开启后恢复 10–30 秒设置与超时自动代选。
- [ ] 无时限时画家断线/离局，宽限期结束后本回合作废并顺延到下一回合。
- [ ] 旧协议版本客户端被拒。
