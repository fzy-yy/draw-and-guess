# 局域网启动与排查

## 加入流程

1. 主机连接家庭、宿舍或办公室可信局域网，在项目根目录执行 `pnpm build`，然后执行 `pnpm start`。
2. 终端会输出 `http://192.168.x.x:5174` 等候选地址。主机可访问 `localhost`，其他设备必须输入局域网地址。
3. 其他设备连接同一 Wi-Fi 或有线网，打开该地址并确认随机昵称和纯色圆形头像。
4. 登录成功后，玩家会实时出现在允许发现的在线列表中，并直接看到当前服务的全部公开房间；点击“加入”即可进入。

浏览器不会扫描局域网。没有访问当前地址、尚未登录或关闭“允许在线发现”的设备不会显示。

## 常见问题

- **连接超时/地址不可达**：确认 IP 未变化、设备处于同一网段，并优先使用主机终端本次输出的地址。
- **端口占用**：Windows PowerShell 使用 `$env:PORT=5180; pnpm start`，macOS/Linux 使用 `PORT=5180 pnpm start`。
- **防火墙阻止**：允许当前 Node.js 在“专用网络”通信，或为所用 TCP 端口添加入站规则；不要将服务开放到公网。
- **访客 Wi-Fi/AP 隔离**：部分路由器禁止无线设备互访，关闭客户端隔离或改用普通局域网。
- **多网卡**：终端会逐条列出候选 IPv4；可用 `ipconfig`/`ifconfig` 对照正在使用网卡。
- **版本不兼容**：刷新页面；仍提示不兼容时，清除浏览器缓存并确保主机使用同一份构建产物。
- **主机关闭**：所有内存房间和战绩都会清空，这是首版设计；重新启动并建房即可。
