# RoomSettings 产品可达性

三档预设由 `packages/config/src/room-presets.ts` 的纯函数统一映射。创建 UI 通过“容量 + 预设”生成完整设置；房主进入房间后可在基础/高级设置中逐项编辑。服务端仍对完整对象做独立验证，不能依赖客户端控件范围。

| 字段                     | 创建 UI    | 编辑 UI            | 规则摘要                         | 服务端验证          | 自动化测试                     |
| ------------------------ | ---------- | ------------------ | -------------------------------- | ------------------- | ------------------------------ |
| `maxPlayers`             | 直接选择   | 基础设置           | 始终展示                         | 整数、2～6          | 预设纯函数、规则组件、房间/E2E |
| `roundsPerPlayer`        | 由预设映射 | 基础滑块           | 始终展示                         | 整数、协议范围      | 预设纯函数、服务端规则测试     |
| `drawSeconds`            | 由预设映射 | 高级“作画时间回退” | 始终展示并说明词条覆盖           | 整数、协议范围      | 预设纯函数、规则组件、假时钟   |
| `chooseSeconds`          | 由预设映射 | 基础滑块           | 与预设不同时展示                 | 整数、协议范围      | 预设纯函数、规则组件、假时钟   |
| `optionCount`            | 由预设映射 | 基础滑块           | 与预设不同时展示                 | 整数、协议范围      | 预设纯函数、规则组件、开局词数 |
| `showWordLength`         | 由预设映射 | 高级开关           | 与预设不同时展示                 | 布尔值              | 预设纯函数、规则组件、快照测试 |
| `progressiveHints`       | 由预设映射 | 高级开关           | 提示组合与预设不同时展示         | 布尔值              | 预设纯函数、提示调度测试       |
| `structuredHintsEnabled` | 由预设映射 | 高级开关           | 提示组合与预设不同时展示         | 布尔值              | 预设纯函数、提示调度/HUD 测试  |
| `hintStartRatio`         | 由预设映射 | 高级滑块           | 启用结构化提示且与预设不同时展示 | 协议比例范围        | 预设纯函数、提示调度测试       |
| `guessBaseScore`         | 由预设映射 | 高级滑块           | 与预设不同时展示                 | 整数、协议范围      | 预设纯函数、计分测试           |
| `scoreMode`              | 由预设映射 | 高级选择           | 与预设不同时展示                 | `standard` / `flat` | 预设纯函数、计分测试           |
| `allowPlayerInvite`      | 由预设映射 | 基础开关           | 与预设不同时展示                 | 布尔值              | 预设纯函数、邀请领域测试       |
| `allowPause`             | 由预设映射 | 高级开关           | 与预设不同时展示                 | 布尔值              | 预设纯函数、暂停生命周期测试   |
| `allowWordReroll`        | 由预设映射 | 基础开关           | 与预设不同时展示                 | 布尔值              | 预设纯函数、选词测试           |
| `joinPolicy`             | 由预设映射 | 基础选择           | 与预设不同时展示                 | 三种协议枚举        | 预设纯函数、加入/观战测试      |

本轮没有删除字段或文案：全部字段都有服务端实际消费点，原问题是客户端只有部分入口。高级设置补齐后，不再存在“协议可配置但 UI 不可达”的半成品字段。
