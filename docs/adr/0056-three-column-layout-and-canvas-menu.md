# 0056 · 黄金三栏对局布局、画板双角色右键菜单与趣味机制升级

**状态**：已采纳

- 来源：2026-10-03 综合体验升级与布局重构（规格见 `.scratch/canvas-menu-gameplay-and-layout/spec.md`）。
- 取代：[ADR-0043](0043-game-view-floating-layout.md)（浮层聊天面板覆盖画布）。

## 背景

[ADR-0043](0043-game-view-floating-layout.md) 曾尝试将聊天面板改为覆盖在画布右侧的浮动面板（`FloatingPanel`）。在实际对局中产生了三个致命痛点：

1. **画作严重受阻**：聊天面板展开时硬性遮挡了画布右侧约 25% 的黄金作画区域，画家在右侧画画时猜词者无法看全；
2. **操作心流分裂**：猜词者若为了看画而按键关闭面板，又无法得知其他人的猜测记录（无法排除错误选项），自己想打字猜词还得频繁开合或拖动浮窗；
3. **窄栏文字截断**：原玩家左栏仅 `10cqw`（约 128px），扣除内边距与头像后文字可用宽度不足 60px，导致 4 个字以上的昵称严重截断、分数与状态角标拥挤错位。

同时，画家在紧张作画期间频繁在画布与底部工具条之间长距离移动光标，缺乏就地盲操通道；猜词者在画板上缺乏轻量参与感，错别字反馈生硬，全员猜中后存在无效等待，终局结算缺乏趣味社交荣誉。

## 决策

1. **黄金平衡三栏对局布局（16cqw - 62cqw - 20cqw）**：
   - 彻底废除覆盖在画板上的浮动面板（`FloatingPanel`）、面板拖动逻辑与快捷键 `C` 显隐控制，聊天栏回归流内常驻；
   - **全局统领顶栏（StageHeader）**：保持统一基线与约 `9%~10%` 高度，统领全屏；
   - **左栏（玩家榜 16cqw）**：文字净宽扩展至 120px 以上，8~10 字长昵称与分数优雅分两行展示且不发生截断，独立黑框；
   - **中栏（核心画板 62cqw）**：物理比例达到约 1.28:1（4:3 黄金绘画比例），居中绝对主角，全屏 100% 完整可见，零浮层遮挡，永不拉伸伸缩；
   - **右栏（常驻聊天栏 20cqw）**：独立黑框，流内常驻，单行容纳 15~16 汉字，绝大多数短句猜词不折行，猜词者边看画边打字；
   - 三栏采用独立画框陈列风格，栏间保留 `0.8cqw` 间隔，外留白各 `0.2cqw`，形成 `100cqw` 物理闭环。
2. **画板双角色右键菜单体系**：
   - 复用全局单例 `ContextMenu.vue`，拦截画板右键事件；
   - 画家菜单：画笔/橡皮/油漆桶/吸管切色、撤销/重做、复制/下载、清空画布（触发 `ConfirmDialog.vue` 二次确认）；
   - 猜词者菜单：复制/下载、快捷发言短语、微表情互动；
   - 具备手势防冲突守卫（作画中屏蔽右键；菜单展开时点击画板仅关闭菜单且 100% 阻断墨迹生成）；
   - 导出源直接取自 720p 纯净逻辑画布，`navigator.clipboard.write` 在局域网非 HTTPS 受阻时自动静默降级为文件下载并提示 Toast。
3. **画布全员轻量微表情广播（👍 / ❓ / 🔥）**：
   - 协议新增 `game:canvas_ping` 事件，受房间规则 `allowCanvasReactions`（默认开启）管控与单人 1.5 秒滑动窗口限频保护；
   - 广播给全员在线连接（不入持久化与笔画历史），画板维护临时气泡队列（上限 6 个），1.2 秒向上浮起淡出。
4. **猜词「差一个字」私密提示与全员猜中立即提前结算**：
   - 答案为服务端绝对秘密，因此由服务端在猜词未命中时计算编辑距离，答案字数 $\ge 2$ 且距离等于 1 时，向当前玩家独占 Socket 定向推送私密通知（公屏不泄漏），受房间规则 `allowNearMissHint`（默认开启）管控；
   - 服务端在每次猜中后，若全员猜词者均已猜中，立即截断倒计时定时器切入 `round_result` 回合结算，消除垃圾时间。
5. **画家 +20 即时飘字、大厅席位点阵与终局荣誉称号**：
   - 猜中时画家视角浮现金色 `+20` 飘字与金币音；
   - 大厅房间卡片增加 6 席位可视化点阵（实心入座小圆 vs 虚线空位圈）；
   - 聊天流系统消息与猜对通报增加三级分层着色；
   - 客户端纯函数推导「神笔马良」、「灵魂画手」、「读心大师」、「积极分子」并渲染在 `GameResult` 玩家卡片上，不改动数据库表结构。

## 后果

- 画布成为屏幕正中央无可争议的绝对视觉焦点，彻底告别浮动面板遮挡画作的顽疾；
- 猜词者视线在“中宫看画”与“右侧看词”之间平行扫视，边看边猜行云流水，不再需要频繁开关或拖拽窗口；
- 玩家长昵称完整舒展，大厅空位一目了然，猜词差一字获得私密正向引导，全员通关立即切入下一阶段，终局结算充满社交趣味；
- 取代 ADR-0043 中的浮层布局决策；协议版本递增为 `'17'`。
