# 0057 · 回合画作快速重播与结算流程优化

**状态**：已采纳

- 来源：2026-10-04 回合画作重放体验与对局结算细节优化。

## 背景

在原本的回合结算流程中，存在以下体验痛点：

1. **画作在猜词结束瞬间被粗暴遮挡**：作画阶段结束后，客户端直接以 `v-if="store.room.phase !== 'drawing'"` 渲染带有 `bg-paper` 背景的遮罩，使画布在瞬间变为大片空白，玩家无法欣赏画家最终完成的完整作品；
2. **缺乏画作精彩回顾环节**：猜词者往往专注于猜词，错过了画家的运笔构思细节，回合结束缺乏 3 秒画作从第 0 笔至末笔的快速回顾体验；
3. **结算面板层次欠缺且阻挡看画**：回合结算弹窗直接遮挡画布中央，玩家若想看画只能等下一局；同时答案文字缺乏色彩对比与视觉重心，画家得分未与猜词者整齐列出；
4. **终局倒计时割裂与按钮细节瑕疵**：终局结算倒计时独立为底部小字，未与操作按钮有机结合；大厅/房间等待页中准备按钮与开始按钮存在边距微小偏差。

## 决策

1. **新增 `allowRoundReplay` 房间规则与 3 秒精彩重放**：
   - 在房间规则中新增 `allowRoundReplay`（默认开启）；
   - 当作画结束进入 `round_result` 时，服务端总时长设定为 8 秒（开启重播时为 3 秒重播 + 5 秒结算；关闭时为 5 秒）；
   - 客户端 `DrawingReplayMachine` 新增 `speedrun()` 引擎，在 3 秒内利用 RAF 流畅将笔迹从 0 到末笔高速递进重现，期间结算弹窗暂不弹出，顶栏显示重播状态；
   - 3 秒结束后自动弹出结算弹窗，倒计时从 5 开始流转。
2. **画布全生命周期画作保留与延迟清空**：
   - 修复 `GameView` 状态遮罩，在 `round_result` 期间不遮挡画布，保证画布画作在结算期 100% 完整可见；
   - 画布仅在倒计时归零真正切入下一轮选词（`choosing_word`）时清空。
3. **回合结算弹窗重构与主动关闭看画机制**：
   - 答案样式改为黄色粗体大字（`text-yellow font-bold text-fs-24 tracking-[0.16em]`），视觉层级分明；
   - 将画家本回合得分作为条状项目置于得分列表第一项，后跟猜词玩家；
   - 底部居中新增 `进入下一轮( 5 )` 按钮，玩家点击后本地关闭弹窗，使视野无阻挡欣赏画作并可通过右键菜单保存画作，倒计时结束服务端权威切入下一轮。
4. **终局结算与房间排版优化**：
   - 移除最终战报中荣誉称号徽章的边框，呈现更轻盈通透的纯色浅底胶囊；
   - 将自动返回房间倒计时直接融入 `再来一局( N )` 按钮中，消除下方冗余独立文案；
   - 消除房间等待页非房主准备按钮的 `my-[0.8cqh]` 边距差异，图标与文字严格水平垂直居中。

## 后果

- 回合衔接更具观赏性与派对氛围，画家的创作过程得到充分展现与赞叹；
- 玩家可自由决定关闭弹窗静心看画或保存作品，操作自由度大幅提升；
- 规则配置由服务端权威维护，向下兼容。
