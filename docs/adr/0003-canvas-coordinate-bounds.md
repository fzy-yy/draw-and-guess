# 0003 画布归一化坐标统一映射到 `canvas-1`

- 状态：已采纳
- 来源：`bug-审查报告.md` #8

## 背景

画布坐标一律归一化到 `[0, 1]`。描边侧原先把 `x` 映射为 `x * canvasWidth`，
`x = 1` 会落到像素 `canvasWidth`——**越过最后一个合法像素** `canvasWidth - 1`；
而洪泛填充在同一个归一化点上把种子 clamp 到 `canvasWidth - 1`。
同一个点、同一份历史，描边与填充落在相邻的两个像素上，右下边缘出现 1px 不一致
（`round` 线帽被半裁切）。

## 决策

- 描边与填充**共用同一映射**：`x * (canvasWidth - 1)` / `y * (canvasHeight - 1)`；
- 归一化 1 明确表示「最后一个合法像素」，而不是「画布外一像素」；
- 越界点由上游的 `[0,1]` 约束保证，不在渲染层再放宽。

## 后果

- 描边与填充在边缘像素上语义一致，右下 1px 差异消失；
- 代价：`x = 1` 的笔画不再绘制到画布之外，边缘线帽可能被画布边界裁掉一半——
  这是「像素索引语义」应有的结果，且与填充一致。
