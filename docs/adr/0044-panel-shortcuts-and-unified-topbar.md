# 0044 · 对局面板显隐快捷键与顶栏高度统一

**状态**：已采纳

- 来源：2026-10-01 对局界面重设计后的交互收口（承接 [ADR-0043](0043-game-view-floating-layout.md)）。
- 调整：[ADR-0043](0043-game-view-floating-layout.md) 第 1 条「顶栏收窄到 `9cqh`」被本 ADR 第 3 条取代。

## 背景

浮层布局上线后暴露两个问题：

- **面板没有键盘入口**：玩家 / 聊天 / 工具条只能点顶栏按钮开合，键盘玩家每局都要来回移动鼠标。
- **顶栏高度跨页面不一致**：大厅、房间等待页、设置页的顶栏都是舞台高度的 `11%`，而对局顶栏为了给画布让位被收到 `9cqh`。切进对局时整条顶栏会「跳一下」，视觉上像是两个不同的应用。
- 聊天面板的键盘入口还有一个额外约束：**回车同时是猜词输入框的发送键**，如果让回车充当开关，就会与「打字回车发送」争夺同一个按键。

## 决策

1. **三个面板各有一个可配置单键快捷键**：玩家 / 聊天 / 工具条，默认 `P` / `C` / `T`，
   随其余本地设置一起持久化；沿用既有「无修饰键单字符 + 全组不重键」校验
   （工具键与面板键共用一个键位空间，避免一次按键触发两个动作）。
2. **聊天面板额外固定一个回车键，语义刻意不对称**：回车**只能打开聊天面板或聚焦猜词框，永不隐藏**；
   真正的开 ↔ 关由可配置的那个键承担。这样回车在「输入框聚焦时发送」与「未聚焦时打开/聚焦」之间
   各司其职，不会互相抢占。
3. **顶栏高度统一为舞台高度的 `11%`**：对局顶栏由 `9cqh` 回调为 `11cqh`，与大厅 / 房间 / 设置页
   的 `grid-rows-[11%_…]` 一致；画布不再从顶栏高度里省，改由浮层布局本身腾出的空间承担。

## 后果

- 键盘玩家可以不离开键盘完成「开聊天 → 打字 → 回车发送」；回车不会误关面板。
- 跨页面切换不再有顶栏高度的跳动；代价是对局画布高度少了约 2% 的舞台高。
- 键位空间多占用三个单字符，设置页的冲突检测自动覆盖（同一份 `shortcutRows`）。
- 工具条快捷键对非画家是**无操作**（该面板只对画家存在），不做「按了没反应」的静默失败之外的额外提示。
