# 0043 · 对局界面改为浮层布局

**状态**：已采纳

- 来源：2026-10-01 对局界面重设计（原型经多轮评审收敛，规格见 `.scratch/game-ui-redesign/spec.md`）。

## 背景

对局界面原为 **3×3 网格**（`17% | 61% | 22%` × `11% | 76% | 13%`）：顶栏占满首行，中行是
「玩家得分条 · 画布 · 聊天三列」，末行是绘图工具栏。三处固定分区把画布压成中间 61% 宽、76% 高，
而玩家与聊天面板无论是否被需要都常驻占位；顶栏又因「当前画家 + 结构化提示」被迫保持 11% 的高度。

结果是**画布小、分区僵**：玩家想看清画作时无法把面板让开，工具栏固定占掉底部一整行，
顶栏的两块信息还与玩家面板、题目遮罩重复。

## 决策

把对局界面改为「**固定顶栏 + 铺满画布 + 浮动面板 + 底部横向工具条**」：

1. **顶栏收窄到 `9cqh`**：`ROUND` 在最左，面板开关按钮紧排其右；删掉「当前画家」与提示区
   （提示的去留见 [ADR-0042](0042-remove-structured-hints.md)），保留题目、倒计时、网络、暂停、设置、全屏。
2. **画布铺满顶栏以下整块**：只留线性边距，并加黑色描边、圆角（与浮层圆角同值）与极小边距，
   使画布边界在纸色舞台上清晰可辨。
3. **玩家与聊天浮层化**：改为可拖动、可关闭、默认打开的浮层面板，纵向撑满画布高、贴左右两缘；
   顶栏开关与面板内关闭按钮写同一份开关状态；出入场统一「淡入淡出 + 缩放」。
4. **绘图工具条浮于画布底部**：单行、无阴影、与图标按钮尺寸相适应，除画笔大小数值外不显示文字，
   可由顶栏「工具」按钮整体收起。
5. **样式收敛为共享组件**：浮层面板壳、玩家面板、底部工具条、画笔数值控件提升为生产共享组件，
   方形图标按钮、圆形色板按钮、分组分隔线等相同样式抽为公共原语，替换原先散落的行内长串。

## 后果

- 画布面积显著增大；用户可按需收起或拖开面板，工具栏不再固定吃掉一行。
- 顶栏更窄，且不再承担「谁在作画」这一可由玩家面板回答的信息，减少重复。
- 代价：定位由网格改为「铺满 + 绝对定位浮层」，面板遮挡关系交给用户自行摆放（默认摆位保证不互相遮挡）；
  浮层需要处理拖动夹取、置顶与开合联动，复杂度从布局转移到交互组件。
- 取代组件：`ScoreStrip` → `PlayerPanel`，`DrawingToolbar` → `CanvasToolbar`，两者连同其测试一并移除。
