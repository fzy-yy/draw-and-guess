# 分诊标签

工程技能使用五个规范分诊角色；本文件把这些角色映射到本仓库议题跟踪器实际使用的标签字符串。
（本地 Markdown 跟踪器中，标签字符串即写在议题文件顶部的 `Status:` 行。）

| mattpocock/skills 中的角色 | 本仓库使用的标签  | 含义                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 维护者需要评估此议题       |
| `needs-info`               | `needs-info`      | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent` | 已完整定义，可交给 AI 代理 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现               |
| `wontfix`                  | `wontfix`         | 不予处理                   |

当技能提到某个角色（如「贴上 AFK-ready 分诊标签」）时，使用本表右列对应的标签字符串。
如需换成自己已有的词汇，直接编辑右列即可。
