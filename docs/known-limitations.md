# 已知限制

- 在线发现列表只包含已经访问并登录当前 Node.js 服务、允许被发现的玩家；项目不会扫描局域网设备。
- 服务端严格使用进程内存：重启后玩家、公开房间、身份令牌、邀请、画板和分数全部清空。
- 局域网 IP 可能在路由器重新分配地址后变化，应以每次启动终端输出为准。
- 所有房间固定公开且只能从大厅列表或定向邀请加入；不提供私密房间、密码、房间码、邀请链接或二维码。
- 首版词库不支持别名；答案只匹配 `vocabulary.md` 标准词面，并规范化空格、Unicode 与拉丁大小写。
- 画布只在内存中保留当前回合的自由笔画和区域填充命令；超过配置上限时丢弃最早命令以保护内存。填充基于当前 Canvas 像素执行，封闭边界需要连续且无明显缺口。
- 纯色头像只保存安全 `#RRGGBB` 值，不支持图片、SVG 人物、URL、上传、粘贴或拖放头像。
- 音效由 Web Audio 本地合成，浏览器首次用户交互前不会播放；不包含远程音乐资源。
