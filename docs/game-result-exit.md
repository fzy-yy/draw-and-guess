# 最终结算退出状态机

最终结算由服务端同时维护两个私有时限：最短展示期 `gameResultMinSeconds` 和无条件自动返回上限
`gameResultAutoReturnSeconds`。客户端只展示服务端快照中的截止时间和操作能力，不能自行切换阶段。

- 进入 `game_result` 时清空所有成员的 `rematchReady`，冻结排行榜并启动两个权威计时器。
- 普通成员点击“再来一局”只把自己的 `rematchReady` 置为 `true`；重复请求不递增版本。
- 房主点击全局返回会同时登记自己的意愿和 `hostReturnRequested`。最短展示期结束前只排队，不能跳过
  结算；展示期结束后由服务端一次性切换到 `waiting`。
- 最短展示期结束后，房主已请求或所有下一局有效成员均 `rematchReady` 时立即返回。有效成员即未
  离局的普通成员，已离局成员不参与条件判断。
- 自动返回上限到期后，无论意愿状态如何均返回等待，避免房间永久停在结算页。
- 结算中成员退出或断线会重新评估条件。房主断线按既有规则迁移给在线参赛成员，新房主获得全局
  返回权；已离局成员不能接管房主。
- 转入 `waiting` 时清除对局、两个结算计时器、离局成绩卡和全部 `rematchReady`，保留房间成员并
  让所有普通成员重新准备。
- 已经位于 `waiting` 或收到阶段切换后的迟到/重复请求时直接按成功处理，不返回
  `INVALID_PHASE`。

两个时长位于服务端私有配置，不能进入浏览器公开配置。协议只公开绝对截止时间、当前观看者是否
可执行房主全局返回，以及每个成员的 `rematchReady` 状态。
