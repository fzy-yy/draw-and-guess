# `next_game` 中途候场语义

`RoomSettings.joinPolicy = 'next_game'` 表示对局已经开始后仍允许新玩家占用一个房间席位，
但该成员以 `waitingForNextGame=true`、`spectating=true` 的候场身份进入，直到房间真正回到
`waiting` 阶段才转为普通成员。

- 候场成员占用 `maxPlayers` 容量并出现在成员列表和大厅人数中；房满后继续拒绝加入。
- 当前局内不进入画家顺序、总回合数、最低在线人数、猜词、聊天互动、计分、全员猜中判断、
  当前局排行榜或战报。
- 快照按非参赛视角裁剪：作画中只能看到公开遮罩、提示、画布和消息；不能获得答案、候选词或
  画家权限。回合结算和最终结算可看到当时已公开的答案与冻结排行。
- 候场成员不能接任房主。房主离开或断线迁移时只选择当前局普通可玩成员；没有候选人则按既有
  规则关闭房间。
- 候场成员主动退出时直接离开房间；断线时不保留当前局席位，立即释放容量，玩家身份仍按既有
  恢复宽限保留在大厅层。
- 从 `game_result` 返回等待，或开局倒计时被取消而返回等待时，候场成员自动清除候场/观战标记，
  分数和局内统计保持初始值，并以 `ready=false` 成为下一局普通成员。纯 `spectate` 观战者不会被
  自动转为参赛成员。

由于 `RoomMember` 推送新增候场和再来一局状态字段，该变更当时把协议版本提升到 `10`（历史设计记录；现行协议为 `16`，见 `packages/shared/src/protocol/constants.ts`）。
