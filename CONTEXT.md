# CONTEXT · 领域词表

> 本仓库的领域语言（单上下文布局，见 `docs/agents/domain.md`）。议题、提案、测试名与
> 注释指称这些概念时使用下列术语；出现同义漂移即为信号，要么改回本表用词，要么来这儿补条目。
> 首批由 2026-09-25 架构评审（候选 C1）创建，收录既有 AGENTS/ADR/代码中的核心词，非穷举。

| 术语                                             | 一句话定义                                                                                                                                                                  | 权威出处                                                           |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 服务端权威（authoritative server）               | 身份、房间、阶段、答案、计时、绘画资格与分数全部由服务端裁决；客户端只发带 requestId 的操作请求                                                                             | AGENTS「架构与实现约定」                                           |
| 角色裁剪快照（role-scoped snapshot）             | 公开数据结构按观看者角色（画家/观众/已离局）生成，服务端秘密字段绝不进快照                                                                                                  | `apps/server/src/snapshot.ts`                                      |
| 幂等 ack（idempotent ack）                       | 客户端请求带 requestId，服务端缓存成功 ack 并对并发重复共享执行 Promise，超时以同 ID 重试                                                                                   | ADR-0012、`apps/server/src/protocol/binder.ts`                     |
| 可见文案（ui strings）                           | 界面直接可见的文案：渲染文本、输入框 placeholder、Toast/请求提示与元信息；位于 `strings.ui`                                                                                 | `packages/strings/src/ui/`、`test/unit/strings-layering.spec.ts`   |
| 无障碍文案（a11y strings）                       | 仅用于辅助技术与悬浮的文案：`aria-*` 绑定、图标按钮 label 与原生 `title`；位于 `strings.a11y`；双用途文本拆为两个 key                                                       | `packages/strings/src/a11y/`、`test/unit/strings-layering.spec.ts` |
| 服务端文案（server strings）                     | 服务端产生、经事件/ack 到达界面的文案（错误、系统通知、词库校验）；独立顶层导出 `serverStrings`                                                                             | `packages/strings/src/server.ts`                                   |
| 版本化推送（versioned push）                     | 服务端主动事件一律 `createServerPush(event, data)` 信封（protocolVersion↔data 编译期配对），客户端先 Zod 解码再过快照门禁                                                   | `packages/shared/src/protocol/push.ts`                             |
| 快照门禁（snapshot gate）                        | 房间/对局/回合/状态版本/画布修订的客户端统一裁决：accept / ignore / resync                                                                                                  | `stores/snapshot-gate.ts`                                          |
| 席位（seat）                                     | 房间内成员的座位编号与颜色（SeatGrid 2×3 矩阵），离房释放、移交房主改其归属                                                                                                 | `SeatGrid.vue`、`room-membership-service.ts`                       |
| 公开房 / 私密房 · 私密短码                       | 公开房进大厅列表；私密房仅凭服务端生成的短码或定向邀请加入                                                                                                                  | AGENTS、`room.ts`(handlers)                                        |
| 恢复令牌（recovery token）                       | 玩家短期身份凭证：落盘仅 SHA-256 摘要、成功恢复必旋转；不是公开快照字段                                                                                                     | AGENTS「配置、安全与敏感信息」                                     |
| 回合流转状态机（round state machine）            | LEGAL_PHASES 白名单裁决阶段转换，非法即 INVALID_TRANSITION                                                                                                                  | `round-machine.ts`、`pure.ts`                                      |
| 作画资格（drawing turn）                         | 每回合由服务端指派画家；笔画/填充按序号单调递增，超预算/越资格被拒                                                                                                          | `drawing-service.ts`                                               |
| 绘图命令历史（drawing command history）          | 权威历史只增不删，达 `maxHistoryCommands` 拒绝新增（撤销/清空释放名额）；橡皮/填充只传点击与颜色，像素由客户端重放                                                          | ADR-0010、`drawing-service.ts`                                     |
| 画布同步游标（canvas sync cursor）               | 成员最近一次快照已同步到的权威绘图序号（`member.lastSyncedSeq`）：整帧下发推进、历史作废重置，差分快照据此只补新增笔画                                                      | `domain/drawing/canvas-sync.ts`                                    |
| 画布重放状态机（Drawing Replay Machine）         | 「权威历史 → 逻辑栅格」的单一所有者：增量 vs 整帧决策、世代取代、undone 过滤、后备缓冲原子提交与在途预览全在其内                                                            | ADR-0018、`canvas/replay-machine.ts`                               |
| 原子换入（atomic commit）                        | 重放只画进后备缓冲，整帧成功后一次性 clearRect+drawImage 换入逻辑层；被取代的重放零可见副作用                                                                               | ADR-0017                                                           |
| 渲染态 / 提交态两把锁（render / submit lock）    | 渲染态＝重放里有填充在算（归画布重放状态机）；提交态＝本地填充待权威修订追平（归 useFillSession）。合成 canFill 门禁                                                        | ADR-0009、ADR-0018                                                 |
| 填充降级（fill degradation）                     | Worker 失败终止重建 + 同一 ImageData 主线程降级恰一次；彻底失败请求权威快照                                                                                                 | ADR-0009、`flood-fill-worker.ts`                                   |
| 笔画批次（pending stroke batch）                 | 一笔按 maxPointsPerBatch 分批上送、序号接续（startPointIndex）；批失败即该笔回滚并请求权威快照                                                                              | `useStrokeSession.ts`                                              |
| 词库包（vocabulary package）                     | 词条只剩词面/合集/别称；分类白名单（category_enum）与难度、可绘制性、提示、启用位均已删除，合集由服务端自动聚合                                                             | ADR-0046、ADR-0048、ADR-0053、`vocabulary/`                        |
| 词条合集（word collection）                      | 词条归属的一组词集合名称（玩家可自定义）；取消枚举限制，服务端自动检测并聚合，供前端筛选并配合全选快速启用一组词                                                            | ADR-0053、`sqlite-provider.ts`                                     |
| 单回合时长（round duration）                     | 房主在 60/90/120/150 四档里选一个（默认 120），它是作画与猜词的唯一时长口径，词条不再参与                                                                                   | ADR-0046、`packages/config/src/game.ts`                            |
| 自定义题目（custom word）                        | 画家在选词阶段输入自己的词直接开画；房主开关 `allowCustomWord`（默认关），服务端合成无元数据词条并拒绝撞词                                                                  | ADR-0045、`domain/vocabulary/custom-word.ts`                       |
| 选词阶段不限时（untimed choosing）               | `allowChooseTimeLimit` 关闭时不写截止时间（`phaseEndsAt = 0`）、不自动代选，唯一兜底是画家离开/掉线                                                                         | ADR-0045、`round-machine.ts`                                       |
| 固定 100 分制（fixed 100-point scoring）         | 猜词者按猜中顺序得 100/80/60/40/20，画家每人 20 分、单回合上限 100；不再有速度/顺序/满员奖与词条权重                                                                        | ADR-0047、`scoring.ts`                                             |
| 遮罩揭示节奏（mask reveal schedule）             | 按渐进间隔逐格揭示答案字符（保留末尾非标点字符，避免直接泄露答案）；结构化提示已移除                                                                                        | ADR-0001、`hint-scheduler.ts`                                      |
| 成员事实（member facts）                         | 房间成员状态的单一具名口径：占席 / 可玩 / 在线可玩 / 进榜，外加连接三态与阶段标称时长；计分、房主迁移、选画家、自动暂停与快照共用                                           | ADR-0023、`domain/room/member-facts.ts`                            |
| 阶段事实（phase facts）                          | 阶段分类白名单的单一具名口径：对局中（含暂停）/ 可暂停 / 可结算三组谓词；阶段标称时长仍归成员事实；时序写入（含暂停现场与结算事实）统一归 RoundMachine                      | ADR-0040、`domain/room/phase-facts.ts`                             |
| 占席 vs 可玩（occupiesSeat / isActivePlayer）    | 占席＝未离局（用于容量与大厅人数）；可玩＝未离局且可参与准备 / 画家 / 计分（当前两者同为 `!leftGame`，但语义与调用点不同，仍分开命名）                                      | `domain/room/member-facts.ts`                                      |
| 进榜口径（final ranking scope）                  | 最终榜单包含 `room.members` 全员：主动退出本局者以冻结的 leftProfile 展示成绩卡，成绩属于本局历史                                                                           | ADR-0023、`scoring.ts`                                             |
| 回合所有权（round ownership）                    | 阶段写入、准备失效、对局消息/系统通知与候选抽取、画家轮换只归 RoundMachine；RoundContext 是运行时/副作用窄端口，GameService 退为请求 API 与装配                             | ADR-0024、`round-machine.ts`                                       |
| 重同步模块（resync module）                      | 客户端权威自愈单一入口：受限全量重同步（冷却/在途/世代与房间有效性/重解析/再采纳）与会话失效跨域重置（世代自增 + 清房间 + 清词库）                                          | ADR-0025、`stores/resync.ts`                                       |
| 诊断内核（bounded diagnostics）                  | 客户端三处脱敏诊断的统一容器与格式化：有界入队、副本导出、清空，以及只记字段路径与错误类别的 Zod 问题描述                                                                   | ADR-0026、`utils/bounded-diagnostics.ts`                           |
| 词库弹窗会话（vocabulary dialog session）        | 词库弹窗的生命周期：打开→拉取→按世代作废迟到结果→关闭（取消在途）→保存成功才关闭；视图模式不属于会话                                                                        | ADR-0027、`useVocabularyDialogSession.ts`                          |
| 客户端房间事实（client room facts）              | 阶段文案与可玩成员判定的单一具名口径（与服务端 member-facts 对齐）；榜单与占席数是不同语义，不复用                                                                          | ADR-0028、`utils/room-facts.ts`、`utils/phase-text.ts`             |
| 浅层包装（shallow wrappers）                     | 图标按钮与视觉包装组件（Base/Icon/Round/Square、HudPill/OverlayCard/RuleRow/StageHeader/SectionHeader）是为消除调用点长串而抽取的；删除测试判定删除只会搬移复杂度，保持现状 | ADR-0029                                                           |
| 猜中礼花（guess confetti）                       | 本机反馈：`me.guessed` 严格跃迁（false→true）触发一次全屏礼花，不枚举阶段；`prev===false` 防止重载补放                                                                      | ADR-0031、ADR-0033、`useGuessConfetti.ts`                          |
| 逐字遮罩（progressive mask）                     | 题目遮罩按节奏逐格揭示答案字符，是猜词者唯一的题目线索；结构化提示（词条 hint 文案）已从对局链路移除                                                                        | ADR-0042、ADR-0001                                                 |
| 黄金三栏布局（golden ratio three-column layout） | 对局主舞台由 16cqw 玩家榜 + 62cqw 4:3 黄金画板 + 20cqw 常驻聊天栏组成，画板居中全屏绝对主角，零浮层遮挡                                                                     | ADR-0056、`GameView.vue`                                           |
| 底部工具条（bottom toolbar）                     | 浮在画布底部、单行 icon 化的绘图工具条；对画家自动显示，猜词者隐藏且不可被收起；最左侧提供六点拖动手柄支持在画布内移动位置，换人或新回合自动重置居中                        | ADR-0054、`CanvasToolbar.vue`                                      |
| 顶栏按钮（StageHeaderButton）                    | StageHeader 顶栏内的统一操作与状态按钮原语（设置、退出、返回与网络状态底层呈现）；统一 4.6cqh 高度、rounded-[0.6em] 圆角与图标文字水平排版                                  | ADR-0052、`StageHeaderButton.vue`                                  |
| 固定等宽倒计时（fixed-width timer pill）         | 对局顶栏倒计时胶囊固定为三位字符等宽容器（`w-[3ch]`），数字居中，不限时以 '---' 居中占位，避免数字位数变化导致胶囊抖动                                                      | ADR-0052、`GameHud.vue`                                            |
| 玩家常驻左栏（player side column）               | 对局界面左侧独立黑框容器（16cqw），容纳 8~10 字昵称完整展示；本人以座位颜色浅色底高亮，画家仅以「作画中」文案与画笔角标表达（无背景色）                                     | ADR-0055、ADR-0056、`PlayerPanel.vue`                              |
| 画板右键菜单（canvas context menu）              | 画布拦截右键呼出全局单例菜单，画家专属创作/撤销/导出/清空二次确认，猜词者专属复制/下载/微表情全员广播；作画中防冲突且点外关闭不留杂墨                                       | ADR-0056、`GameCanvas.vue`                                         |
| 差一字私密提示（near-miss hint）                 | 猜词与答案长度 >= 2 且编辑距离严格等于 1 时，由服务端定向向当前玩家独占推送的私密线索，公屏绝不剧透                                                                         | ADR-0056、`handlers/chat.ts`                                       |
| 作画快速重播（round speedrun replay）            | 回合结束进入结算展示前，客户端在画布上以 3 秒高速递进重现画家从第 0 笔至末笔的全部运笔细节；由房间设置 allowRoundReplay 控制，画布保留画作直至下一回合选词才清空            | ADR-0057、`DrawingReplayMachine`                                   |
