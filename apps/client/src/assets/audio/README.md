# 自定义音效资源目录

请将准备好的 `.mp3` 或 `.wav` 音频文件放入本目录（`apps/client/src/assets/audio/`）。
Vite 会自动收集并建立构建索引，无需修改导入代码。

### 推荐音频文件名清单（全部小写）

| 文件名         | 格式            | 推荐说明                 | 触发时机           |
| :------------- | :-------------- | :----------------------- | :----------------- |
| `click`        | `.mp3` / `.wav` | 清脆、短促的按键音       | 按钮点击、选项切换 |
| `switch`       | `.mp3` / `.wav` | 开关切换音               | 设置项开关切换     |
| `popup`        | `.mp3` / `.wav` | 轻柔弹窗展开音           | 弹窗打开           |
| `close`        | `.mp3` / `.wav` | 弹窗关闭收起音           | 弹窗关闭           |
| `ready`        | `.mp3` / `.wav` | 上扬短和弦               | 玩家点击“准备”     |
| `invite`       | `.mp3` / `.wav` | 提示音                   | 收到组队邀请横幅   |
| `start`        | `.mp3` / `.wav` | 开局号角或提示音         | 对局正式启动       |

### 背景音乐编码规格与体积评估

两首 BGM 统一为 **MP3 128 kbps CBR / 44.1 kHz / 立体声**（由 256 kbps 源文件重编码）：

| 文件            |      源体积 |      现体积 |   降幅 | 重编码前 LUFS | 重编码后 LUFS |    真峰值 |
| :-------------- | ----------: | ----------: | -----: | ------------: | ------------: | --------: |
| `bgm_lobby.mp3` | 1,802,543 B |   902,356 B | −49.9% |         −14.3 |         −14.7 | +1.2 dBFS |
| `bgm_game.mp3`  | 4,079,584 B | 2,040,876 B | −50.0% |         −18.8 |         −19.2 | −0.1 dBFS |

评估方法（只用 ffmpeg/ffprobe，无额外依赖）：

- **响度一致**：`ebur128` 测整轨 LUFS，重编码前后差 ≤0.4 LU（低于 1 dB 的可闻阈），故不做增益补偿——
  两首的真峰值已贴近 0 dBFS，再加增益会削波。
- **听感无明显下降**：用「源 − 重编码」的残差 RMS 量化失真。同码率重编码（256k）得到纯转码地板
  （−52.1 / −61.3 dBFS），128k 候选为 −40.2 / −48.3 dBFS，96k 候选仅再低约 2 dB 却只多省 12% 体积，
  因此取 128k（体积降幅 50%，远超 30% 目标）。
- **两轨之间仍有约 4.5 LU 的响度差**（大厅 −14.7 / 对局 −19.2），属素材本身的差异，不在本次
  「保持各自响度」的范围内；若要统一需带限幅器的 `loudnorm`，属调音决策，未擅自改动。

> 重新评估：`ffmpeg -i <file> -af ebur128=peak=true -f null -`（读输出里的 `I:` 与 `Peak:` 行）。

### 说明与注意事项

1. **命名匹配**：文件名（不包含扩展名）即为音效键名（例如 `click.mp3` 或 `click.wav` 均对应 `'click'`）。
2. **缺省容错**：即使某些文件暂未放入，开发环境仅在控制台给出黄色提示，应用仍能平稳运行，绝不报错中断。
3. **格式推荐**：短促音效推荐使用轻量级 `.wav` 或高压压缩比的 `.mp3`，背景音乐推荐使用 `.mp3`。
