# 自定义音效资源目录

请将准备好的 `.mp3` 或 `.wav` 音频文件放入本目录（`apps/client/src/assets/audio/`）。
Vite 会自动收集并建立构建索引，无需修改导入代码。

> 背景音乐（BGM）系统已整体移除：不再放置任何长循环音乐，只保留下表所列短音效。

### 推荐音频文件名清单（全部小写）

| 文件名         | 格式            | 推荐说明            | 触发时机           |
| :------------- | :-------------- | :------------------ | :----------------- |
| `click`        | `.mp3` / `.wav` | 清脆、短促的按键音  | 按钮点击、选项切换 |
| `switch`       | `.mp3` / `.wav` | 开关切换音          | 设置项开关切换     |
| `popup`        | `.mp3` / `.wav` | 轻柔弹窗展开音      | 弹窗打开           |
| `close`        | `.mp3` / `.wav` | 弹窗关闭收起音      | 弹窗关闭           |
| `ready`        | `.mp3` / `.wav` | 上扬短和弦          | 玩家点击“准备”     |
| `invite`       | `.mp3` / `.wav` | 提示音              | 收到组队邀请横幅   |
| `start`        | `.mp3` / `.wav` | 开局号角或提示音    | 对局正式启动       |
| `drawing`      | `.mp3` / `.wav` | 作画提示音          | 轮到画家作画       |
| `correct`      | `.mp3` / `.wav` | 欢快三连音/清脆铃声 | 猜中词语答案       |
| `tick`         | `.mp3` / `.wav` | 节拍滴答或警报声    | 倒计时最后 10 秒   |
| `round_result` | `.mp3` / `.wav` | 回合小结算音        | 单回合结束展示得分 |
| `game_result`  | `.mp3` / `.wav` | 颁奖典礼/胜利音乐   | 游戏结束展示前三名 |

### 说明与注意事项

1. **命名匹配**：文件名（不包含扩展名）即为音效键名（例如 `click.mp3` 或 `click.wav` 均对应 `'click'`）。
2. **缺省容错**：即使某些文件暂未放入，开发环境仅在控制台给出黄色提示，应用仍能平稳运行，绝不报错中断。
3. **格式推荐**：短促音效推荐使用轻量级 `.wav` 或高压压缩比的 `.mp3`；同名同时存在两种格式时优先使用 `.wav`。
